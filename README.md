# FM27 Exporter

Windows-based, read-only first-team FM27 save exporter.

- Exporter version: **v1.4.5**
- Parser pin: **fmsave==0.12.4**
- Public repository contains exporter code and workflow only.
- Career saves, player-identity cache, export reports and history archives remain in the private `eslaulau/FM27` repository.
- Workflow runs only on manual dispatch on a standard GitHub-hosted Windows runner.

See [SETUP.md](SETUP.md) for the one-time private-repository token setup and [README_EXPORTER.md](README_EXPORTER.md) for usage and scope.
